# Режим «по формату НЦТ» для новых предметов

Сейчас режим есть у химии, права, истории, математики и английского (главный админ; английский — по CSV анализа НЦТ 2022–2026, блоки текстов, разметки `nct_type` в банке пока нет, см. раздел 9 архитектуры); движок читает настройки предмета (`NctConfig`, см. `docs/ARCHITECTURE.md`, раздел 9). Новому предмету нужен свой конфиг по образцу `_shared/nctLaw.ts`. Реестр предметов — `supabase/functions/_shared/examProfiles.ts`:
предмет без профиля режима не видит. Движок (`_shared/nct.ts`) пока написан под химию; ниже — что нужно получить
по новому предмету, чтобы обобщить движок и подключить предмет за один заход.

## Какие данные нужны по предмету
1. **Состав билета**: сколько тестов, соответствий, открытых; баллы за каждый вид; максимум баллов.
2. **Разделы** экзамена: названия, доли баллов (%), порядок на номерах билета (какие номера какому разделу принадлежат).
3. **Темы банка → разделы**: для каждой главы и темы банка — раздел (или «не берётся»). Для химии это `EXTRA_RANGES` и `CHEM_LEVEL_SIZES` в `nct.ts`.
4. **Анализ прошлых лет** — CSV по образцу `nct_2022_2026_tasks.csv`: `год;компонент;вариант;номер;раздел;код_типа`
   (+ желательно уровень сложности). Из него `scratch/nct-subject/gen_slots_generic.py` строит таблицу «тип → частота на номерах раздела».
5. **Справочник типов заданий**: код, раздел, название, номера билета (как `src/lib/nctTypes.ts`).
6. **Запрещённые типы** 1-го круга (если есть правила круга) и **доля баллов из сборника НЦТ** (у химии 40 %).
7. **Сборник НЦТ в банке**: как называется источник (у химии — «ЦВЭ …»).
8. **Сложность** (если у предмета есть деление на лёгкие/средние/сложные) — доли по видам.

## Что сделаю, когда данные будут
1. Разобрать CSV и таблицу типов, сгенерировать `nctSlots` предмета (`gen_slots_generic.py`).
2. Записать профиль в `EXAM_PROFILES`; разделы, состав и баллы в `nct.ts` читаются из профиля, а не из констант химии.
3. Метки типов: классификатор по образцу `scratch/nct/classify.mjs` и ручная проверка выборки; поле `questions.nct_type` общее для предметов.
4. Список типов в форме вопроса/фильтре — по предмету вопроса (сейчас один общий `NCT_TYPES`).
5. Тесты, `docs/ARCHITECTURE.md`, релиз.

Пока не готово: в бота и мини-приложение режим не подключён.

## История (подключена)
Конфиг — `_shared/nctHistory.ts`, слоты — `_shared/nctSlotsHistory.ts`, справочник — `src/lib/nctTypesHistory.ts` (генерация `scratch/ncthist/gen_history.py` из анализа НЦТ по истории 2022–2026). Вид билета 20 + 4 + 2, 40 баллов. Четыре официальных раздела: таджикская история до конца XV века (27 %), с конца XV века (21 %), с 1920 года (27 %), всеобщая история с 1918 года (25 %). Раздел таджикской темы — по периоду (главы банка 1–2 и 3.1–3.3 → первый, 3.4–3.18 → второй, главы 4–5 → третий); вопрос всеобщей истории помечается кодом с префиксом `W_`. Метки типов в банке проставляет разметчик по тексту условия; до разметки режим берёт неразмеченные вопросы тем.

## Биология (подключена)
Конфиг — `_shared/nctBio.ts` (`BIO_CONFIG`, `bioTopicSection`), слоты — `_shared/nctSlotsBio.ts`, справочник — `src/lib/nctTypesBio.ts` (генерация `scratch/nctbio/gen_bio.py` из анализа НЦТ по биологии 2022–2026). Вид билета 20 + 4 + 2, 40 баллов (1 / 4 / 2). Пять разделов — блоки билета: общая биология (№1–5, 33 %), ботаника (№6–10, 22 %), зоология (№11–14, 20 %), анатомия человека (№15–19, 12 %), экология (№20 — один тест, 13 %); соответствия — по одному в общую биологию, ботанику, зоологию и экологию, открытые (ДНК/РНК, генетика, рисунок, список) — в общую биологию. Раздел темы — по главе банка: гл. 1 и гл. 2 темы 1–7 → общая биология, гл. 2 темы 8–10 → экология, гл. 3 → анатомия, гл. 4 темы 1–2 → ботаника, темы 3–20 → зоология, гл. 5 → ботаника. Коды типов — `BIO_` + код анализа (`BIO_CELL`, `BIO_B_ANG`, `BIO_O_DNA`). Квоты сборника НЦТ нет (в банке нет источника с «ЦВЭ/НЦТ» в названии). Метки типов в банке проставляет отдельная разметка; до неё режим берёт неразмеченные вопросы тем.

## Физика (подключена)
Конфиг — `_shared/nctPhys.ts` (`PHYS_CONFIG`, `physTopicSection`), слоты — `_shared/nctSlotsPhys.ts`, справочник — `src/lib/nctTypesPhys.ts` (генерация `scratch/nctphys/gen_phys.py` из анализа НЦТ по физике 2022–2026: 45 вариантов, 103 типа). Вид билета 18 + 2 + 7, 40 баллов (1 / 4 / 2) — во всех вариантах одинаковый. Пять разделов — блоки билета: механика (тесты №1–8, соответствие №19, открытое №21; 14 баллов, 35 %), молекулярная физика и термодинамика (тест №9, открытые №22–23; 5 баллов, 13 %), электродинамика (тесты №10–15, соответствие №20, открытое №24; 12 баллов, 30 %), оптика (тест №16, открытое №25; 3 балла, 7 %), физика атома и атомного ядра (тесты №17–18, открытые №26–27; 6 баллов, 15 %). Раздел темы — по главе банка (глава = уровень курса 1–10): ур.1–3 и 6–7 → механика; ур.4 темы 1–5 → МКТ, 6–8 → электродинамика; ур.5 темы 1–3 → оптика, 4–7 → атом; ур.8 → МКТ; ур.9 → электродинамика; ур.10 темы 1–3 → механика, 4–6 → электродинамика, 7–8 → оптика, 9–10 → атом. В банке сейчас главы 1–4 (глава 3 — 8 тем вместо 9 программных); главы 5–10 подключатся сами после импорта. Коды типов — `PHYS_` + код анализа (`PHYS_OHM`, `PHYS_KIN_GRAPH`, `PHYS_MATCH_F`). Тип в билете до двух раз: одни коды стоят и на тестах, и на открытых. Квоты сборника НЦТ пока нет: источник «ЦВЭ 2026 (Физика)» в банке не импортирован; когда появится — включить `PHYS_QUOTA` (комментарий в `nctPhys.ts`). Метки типов в банке проставляет отдельная разметка; до неё режим берёт неразмеченные вопросы тем.
