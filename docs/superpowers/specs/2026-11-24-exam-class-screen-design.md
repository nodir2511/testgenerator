# «Билеты классу»: экран для показа классу

Согласовано с пользователем 24 ноября 2026.

## Зачем
Преподаватель выводит запуск на проектор или большой экран: класс видит, как войти, сколько осталось времени и кто ушёл со страницы билета.

## Что показывает (по этапам запуска)
- **Ожидание:** крупный QR-код и ссылка, «Вошли: N» и имена вошедших.
- **Старт:** «Скоро начнём…», затем цифры 3-2-1 — как на телефонах учеников.
- **Идёт билет:** крупный таймер, «Сдали N из M», список «Не на странице билета» с именами и временем, маленький QR-код для опоздавших.
- **Конец:** «Время вышло» или «Билет закрыт», «Работы приняты: N из M».

## Решения пользователя
- Имена ушедших со страницы показываются всему классу (не только число).

## Мои решения
- Баллы на общий экран не выводятся.
- Отдельный адрес `/exam/screen/КОД` в новой вкладке (кнопка «На экран» в таблице запуска): вкладку можно перенести на проектор, а таблица остаётся на ноутбуке.
- Страница работает под входом преподавателя: данные читаются по его правам, новых функций в базе нет, ученик по этому адресу ничего не увидит.
- Время — по часам сервера (существующая функция `game_time`), чтобы таймер совпадал с телефонами.
- Экран ничем не управляет: начинает и закрывает запуск преподаватель в таблице.

## Подходы
1. **Отдельная страница под входом преподавателя (выбран).** Без изменений базы, можно вынести на второй экран.
2. Страница без входа по коду, как у «Своей игры». Код знают все ученики — любой открыл бы список имён и ушедших; нужны новые функции в базе.
3. Полноэкранный режим внутри раздела. Проще, но таблица и экран не видны одновременно.
