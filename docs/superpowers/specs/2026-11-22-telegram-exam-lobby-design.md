# Билеты классу: зал ожидания и общий старт — дизайн

Дата: 2026-11-22. Статус: **ждёт одобрения владельца**. Меняет дизайн `2026-11-22-telegram-exam-design.md` (там ученик стартовал сам); остальное оттуда остаётся в силе.

## Зачем
Класс сидит вместе, преподаватель ведёт урок: все должны начать одновременно, преподаватель должен видеть, кому какой вариант достался (чтобы соседям не выпали одинаковые), и сам решает, сколько времени дать.

## Что решил владелец
- Все заходят по ссылке и ждут начала сессии.
- В зале ожидания у ученика на экране **большая цифра его варианта**.
- Преподаватель видит, у кого какой вариант, и **при необходимости меняет вариант** ученику.
- Преподаватель нажимает «Начать» — у всех **обратный отсчёт 3, 2, 1**, затем открывается билет.
- **Время выбирает преподаватель: от 5 до 45 минут.**
- Кто зашёл **после** нажатия «Начать», тоже попадает в сессию, но **время окончания у всех общее** (опоздавший получает остаток).
- Одна попытка на аккаунт Telegram по ссылке — как раньше. Режима «каждый стартует сам» больше нет (мой выбор: два режима не вести).

## Как это работает
Состояния запуска: **ожидание** (старт не нажат) → **идёт** (после «Начать») → **закрыт** (преподаватель закрыл или истёк срок ссылки — 24 часа, как раньше).

Ученик:
```
открыл ссылку → фамилия/имя + язык → ЗАЛ ОЖИДАНИЯ
        «Ваш вариант»
            [ 3 ]            ← большая цифра
   Ждите, преподаватель начнёт сессию
→ после «Начать»: 3 … 2 … 1 → вопросы, таймер до общего конца
→ опоздавший: сразу вопросы, таймер показывает остаток общей сессии
```
Преподаватель (раздел «Билеты классу», до старта):
```
Химия — гл. 1–3        ожидание · пришло 12
  Алиев Али (@ali)        вариант [ 2 ▾ ]
  Каримова Нигина         вариант [ 1 ▾ ]
  Время: [ 30 мин ▾ ]   [ Начать для 12 учеников ]
```
После старта таблица как сейчас (баллы, «идёт», сдано), новые ученики добавляются в неё.

Технические решения (мои, поправьте при несогласии):
- **Старт — серверный момент.** «Начать» ставит `session_start_at = сейчас + 3 секунды` и конец `= session_start_at + время`. Телефоны считают по времени сервера (смещение часов уже есть), поэтому цифры 3-2-1 у всех совпадают.
- **Как телефон узнаёт о старте:** раз в 3 секунды спрашивает сервер (действие `open`). Постоянного соединения нет — проще и легче для слабого сервера (класс из 30 учеников — около 10 запросов в секунду, лёгких).
- **Ключи.** В зале ожидания сервер отдаёт только номер варианта; вопросы — после наступления `session_start_at` (с вырезанными ответами, как сейчас).
- **Смена варианта:** только до старта (после старта ученик уже видит вопросы). Преподаватель выбирает из билетов набора; ученик увидит новую цифру при ближайшем опросе.
- **Время.** `duration_min` задаётся при «Начать» (5–45, шаг 5, по умолчанию 30), проверка в базе. Тексты «30 минут» в сообщении бота, в ссылке для классу и на странице ученика заменяются на «время назначит преподаватель»; в зале ожидания после старта показывается выбранная длительность.
- **Опоздавшие** допускаются, пока сессия не кончилась (`now < конец`); дедлайн попытки = общий конец. Если ссылка закрыта или сессия закончилась — «Приём ответов закрыт».
- **«Начать» нажато дважды** — действует только первое; без учеников начать нельзя.

## Что затронет
- **База:** в `exam_links` — `session_start_at timestamptz` (пусто = ожидание), проверка `duration_min` 5..45; в `exam_attempts` — `deadline_at` может быть пустым до старта; функции `exam_session_start(код, минуты)` (идемпотентна, ставит старт и дедлайн всем ожидающим) и смена варианта (до старта); `exam_attempt_save` принимает ответы только после `session_start_at`.
- **Сервер (`tg-exam`):** `start` → вход в зал ожидания (случайный вариант, без дедлайна); `open` отдаёт `waiting` / `countdown` / `running` и номер варианта; новые действия преподавателя `session_start`, `set_variant`; опоздавшие получают дедлайн = общий конец.
- **Страница ученика:** экран зала ожидания (большая цифра, опрос раз в 3 с), отсчёт 3-2-1, переход в билет; убрать «30 минут».
- **Таблица преподавателя:** режим ожидания (список, выбор варианта, длительность, «Начать»), далее как сейчас.
- **Бот и `link_send`:** формулировка без «30 минут».
- **Тесты:** расчёт состояний и дедлайнов, права доступа (смена варианта чужим преподавателем и после старта отклоняется, запись ответов до старта отклоняется, длительность вне 5–45 отклоняется, повторное «Начать»), тесты чистой логики.
- **Не трогаем:** разбор, Excel, рассылку разбора, правила видимости ответов.

## Риски
- **Ложный старт у ученика** — если у телефона сильно ушли часы: используем смещение по времени сервера, как в нынешней странице.
- **Опрос раз в 3 с** при большом классе — нагрузка небольшая, при необходимости интервал увеличим.
- **Опоздавший в последнюю минуту** получит почти ноль времени — это принятое решение владельца.
- **Если преподаватель не нажмёт «Начать»**, ученики ждут до закрытия ссылки (24 часа).
