# Английский язык: новый предмет с текстами — проект (этап 1)

Дата: 19 ноября 2026. Статус: на согласовании.

## Зачем

Нужен предмет «Английский язык» в банке и генераторе. От остальных он отличается двумя вещами:
он одноязычный (как таджикский) и 16 из 20 тестов билета привязаны к двум текстам
(№ 1–8 — вопросы к тексту, № 9–16 — пропуски в тексте). Сейчас сайт таких заданий не умеет.

Билет по образцу НЦТ 2026 (26 заданий, 20 + 4 + 2):

| № | Задание | Вид на сайте |
|---|---|---|
| 1–8 | текст для чтения + 8 вопросов | тесты с общим текстом |
| 9–16 | текст с 8 пропусками, у вопроса только варианты | тесты с общим текстом |
| 17–20 | отдельные тесты | тест |
| 21–24 | соответствие 4 × 5 | соответствие |
| 25–26 | расставить слова / предложения по порядку | открытый, ответ — цифры («3142») |

## Цели

1. Хранить тексты и их вопросы так, чтобы текст попадал в билет целиком и печатался один раз.
2. Генератор, Word, ключи, бланки, проверка по фото, архив и правка набора работают с английским.
3. Импортировать три сборника English File без клонов, с проверенными ключами.

## Не входит в этап 1

- Режим «по формату НЦТ» для английского (типы по номерам, квоты) — этап 2.
- Дописывание заданий, которых нет в сборниках (главная идея, слово по тексту, синонимы, порядок слов) — этап 2.
- Импорт архива НЦТ 2022–2026 (ключей и текстов для чтения в материалах нет) — этап 2.
- Импорт текстов через форму «Массовый импорт» на сайте: сборники загружаются скриптом.
- Аудирование, кластеры B.

Данные для этапа 2 (получены 19 ноября 2026): официальная таблица распределения — «Хониш» (чтение) 25 ± 2 %,
«Грамматика, лексикология» 75 ± 2 %; знание и понимание 38 ± 2 %, умения и навыки 62 ± 2 %.
При 40 баллах чтение = 10 баллов: № 1–8 (8 баллов) и, по предположению, № 26 «порядок предложений» (2 балла).
Учебники English File 4th edition (Student's Book, Workbook) пользователь присылает PDF-файлами.

## Чего нельзя допустить

- Вопрос к тексту попал в билет без текста или с чужим текстом.
- Из одного текста в билет попала часть вопросов, либо вопросы поменялись местами.
- Изменения сломали билеты остальных предметов (у них `passage_id` пуст, поведение прежнее).

## Подходы

| Подход | Суть | Итог |
|---|---|---|
| А. Текст — отдельная запись | таблица текстов, у вопроса ссылка на текст; вопрос остаётся обычным тестом | **выбран пользователем**: ключи, бланки и метки типов работают без переделки |
| Б. Текст в каждом вопросе | база не меняется | отклонён: текст печатается 8 раз, вопросы разных текстов смешиваются |
| В. Текст + 8 вопросов — одно задание | один «большой» вопрос | отклонён: ломает ключи и бланки (строка на задание) |

## Решения пользователя

- Подход А.
- Главы — уровни (Beginner, Elementary, Pre-Intermediate), темы — юниты по оглавлениям сборников (24 + 35 + 36 = 95), а не по недельному плану.
- Клоны вариантов не импортировать.
- У английского пять клеток для ответа открытого вопроса (в № 25 пять слов).

## Устройство (мои решения, можно поправить)

**База.** Новая таблица `passages`: `id`, `subject_id`, `chapter_id`, `topic_id`, `source_id`, `batch_id`,
`kind` (`reading` | `cloze`), `title`, `content`, `is_deleted`, автор и даты. RLS — как у вопросов
(`can_view_subject` / `can_manage_subject`). У `questions` два новых поля: `passage_id` (ссылка, может быть пустой)
и `passage_order` (место вопроса в тексте, 1–8). Откат партии и мягкое удаление темы скрывают и тексты.

**Вопросы.** Вопрос к тексту — обычный `test` с четырьмя вариантами. У вопроса-пропуска условие — номер
пропуска; проверка «пустой текст» для него не применяется. Задание на порядок — `open`, в условии
пронумерованные слова или предложения, `correct_numeric_answer` — цифры по порядку.
Язык: текст лежит в `content`, полей RU/TG нет (как у таджикского).

**Подбор.** Общая логика в `_shared/ticketing.ts`, чтобы сайт, бот и мини-приложение работали одинаково.
Для предмета с текстами состав задаётся так: текстов для чтения (1), текстов с пропусками (1),
отдельных тестов (4), соответствий (4), на порядок (2). Текст берётся целиком, вопросы идут в порядке
`passage_order`, варианты ответа перемешиваются как обычно. В параллельных билетах на одном месте стоят
разные тексты одной темы, пока хватает; реже использованные — в приоритете. В `generation_params`
`test_count` остаётся 20 — ключи и бланки считают как раньше; число текстов пишется отдельным полем.
Счётчики пула показывают отдельно тексты и одиночные тесты.

**Снимок.** В снимок каждого вопроса текста пишется `passage {id, kind, title, content}` — снимок остаётся
самодостаточным. Word печатает текст один раз перед первым вопросом подряд идущей группы.

**Word.** Перед блоком — строка задания на английском («Read the text and choose the correct answer 1 – 8.»),
заголовок и текст; пропуски в тексте нумеруются номерами билета. Шапка «Variant N». Выбор языка при
скачивании для английского скрыт, файл один.

**Правка набора.** Замена вопроса из текста меняет весь блок (текст + 8 вопросов) на другой того же вида.
«Убрать тему» работает с блоком как с одним местом. Одиночные вопросы — как сейчас.

**Банк вопросов.** В списке у вопроса видно, к какому тексту он относится; фильтр «по тексту»;
окно правки текста (заголовок и содержание). В форме вопроса — выбор текста и места в нём.

**Бланк и ключи** (решение пользователя: как у таджикского). В билете Word и в шаблоне ключей — пять клеток
(`docxExport`, `clusterSlots`, шаблон `taj-cluster`). Бумажный бланк не меняется: у всех предметов 20 + 4 + 2
на нём четыре клетки, поэтому по фото проверяются первые четыре цифры ответа (пятая определяется однозначно).
Для задания из четырёх предложений пятая клетка в билете остаётся пустой.

**Экзамен-кластер.** Английский в книжке берёт блоки тем же подбором; если это окажется большой
отдельной работой — выносится в следующий шаг, а до тех пор выбрать английский в книжке нельзя
(пункт выключен с пояснением).

**Импорт сборников** (скрипты в `scratch/english`, порядок из `CLAUDE.md`): три главы, 95 тем
«1A — verb be (I, you); numbers 0–10 …», источники «English File Beginner / Elementary / Pre-Intermediate
(Test Bank)», партии в `import_batches`. Клоны: внутри юнита тексты с совпадением больше половины
трёхсловных сочетаний считаются одним текстом, остаётся первый; одиночные задания с тем же условием и
тем же верным ответом — одно. По замеру разных текстов для чтения: Beginner 112 из 144, Elementary 210
из 210, Pre-Intermediate 36 из 216. Все ключи проверяются по смыслу; спорные места перечисляются
пользователю. № 20 «Choose the correct sentence» импортируется как обычный тест.
