# Прохождение билета в Telegram — дизайн

Дата: 2026-11-22. Статус: **согласовано владельцем с тремя правками** (обычные наборы; отдельный раздел сайта вместо таблицы в боте; разбор ученику — текстом в чат). План: `docs/superpowers/plans/2026-11-22-telegram-exam.md`.

## Зачем
Сайт выдаёт билеты, но не знает, как их решили: результаты есть только у тех, кто проверяет бумажные бланки по фото.
Нужно, чтобы ученик мог пройти билет в Telegram без бумаги, а преподаватель видел, кто сдал и сколько набрал, и мог отправить ученикам разбор.

## Что решил владелец (в разговоре)
- Преподаватель у готового набора на сайте нажимает кнопку, получает ссылку на бота и отправляет её ученикам.
- Ученик проходит билет внутри Telegram. **Нынешнее мини-приложение преподавателя ученикам показывать нельзя.**
- Вариант ученику достаётся **случайный**.
- Баллы ученик видит **сразу после прохождения**.
- На прохождение **30 минут**.
- Ссылка открыта, пока преподаватель её не закроет, но **не дольше суток**.
- Преподаватель видит **таблицу, которая обновляется по ходу сдачи**: кто сдал (аккаунт ученика) и сколько баллов.
- После — **разбор вопросов**: где ответили неправильно.
- Преподаватель **по кнопке отправляет разбор ученикам** через бота.

## Мои предложения (поправьте, если не так)
- **Только обычные наборы.** Кластерные книжки (4 предмета, 100+ заданий) — отдельным этапом.
- **Одна попытка на аккаунт Telegram по одной ссылке.** Закрыл Telegram и вернулся в пределах 30 минут — продолжает с того же места: каждый ответ сохраняется сразу.
- **При первом входе ученик один раз вводит фамилию и имя.** В таблице у преподавателя — введённое имя и рядом аккаунт (@ник или имя из Telegram): имя в Telegram часто прозвище.
- **Сразу после сдачи ученик видит только баллы**, без верных ответов — иначе первый сдавший перешлёт ответы остальным. Верные ответы приходят с разбором, который отправляет преподаватель.
- **Баллы как при проверке бланков:** тест 1, каждый верный пункт соответствия 1 (до 4 за задание), открытый 2. Ответ открытого вопроса — число; запятая и точка равнозначны.
- **По истечении 30 минут работа сдаётся сама** с тем, что отвечено. Время считает сервер.
- **Отдельный раздел сайта «Билеты классу»** (решение владельца): в нём список запусков, кнопка «Запустить классу» (выбор набора из архива), таблица сдающих, которая обновляется сама, разбор по вопросам, Excel. У набора в архиве и после генерации — кнопка «Запустить классу», ведущая в этот раздел. В боте преподаватель получает ссылку для пересылки и итог при закрытии; живой таблицы в чате нет.
- **Разбор для преподавателя** (на сайте и по кнопке в боте): по каждому вопросу — сколько ответили верно, какой неверный вариант выбирали чаще; вопросы отсортированы от самых проваленных.
- **Разбор для ученика — текстом в чат** (решение владельца): бот присылает вопросы, где ученик ошибся, с его ответом и верным ответом. Индексы и степени заменяются знаками Юникода (H₂SO₄, x²), дроби пишутся через косую черту, вместо рисунка — пометка «[рисунок]». Под сообщением кнопка «Открыть с формулами и рисунками» — та же страница в режиме разбора, для предметов с дробями и картинками.
- **Хранение:** попытки удаляются вместе с набором; имена учеников нигде, кроме таблицы попыток, не хранятся.

Ученик:
```
Бот: 📝 Билет по химии. На прохождение 30 минут, попытка одна.
     [Начать билет]

→ «Вы набрали 31 из 40»
→ позже от бота: разбор текстом (вопрос, ваш ответ, верный ответ) + [Открыть с формулами и рисунками]
```

## Подходы
- **Выбран: отдельная страница экзамена внутри Telegram** (свой адрес `/exam`, свой экран), которую открывает кнопка бота. Данные идут через ту же серверную функцию, что и мини-приложение (`tg-app`), но по отдельным действиям, не требующим привязки к аккаунту сайта. Личность ученика — из подписи Telegram, которую сервер уже умеет проверять. Ключи ученику не отдаются: снимок вопроса перед отправкой очищается от верных ответов, баллы считает сервер.
- Отвергнут: **вопросы сообщениями в чате с кнопками A–D.** Нет дробей и индексов, соответствия и открытые ответы вводить неудобно, 27 вопросов — 27+ сообщений.
- Отвергнут: **пустить учеников в нынешнее мини-приложение с урезанными правами.** Владелец запретил; к тому же оно построено вокруг привязанного преподавателя.
- Отложен: **страница на сайте без Telegram** (по QR в браузере). Не подтверждает личность; можно добавить позже на той же основе.

## Что затронет
- **База:** две таблицы — ссылка на экзамен (код, набор, преподаватель, срок, длительность, сообщение-таблица в чате) и попытки (аккаунт Telegram, имя, вариант, время начала и срок, ответы, баллы, разбор отправлен). Прямого доступа с сайта и без входа нет; преподаватель читает свои результаты, ученическая часть идёт только через серверную функцию.
- **Сервер:** отдельная функция `tg-exam` (ученик: открыть, начать, сохранить ответ, сдать, разбор — по подписи Telegram; преподаватель: закрыть, отправить разбор — по входу на сайт) и правка `telegram-bot` (ссылка `start=exam_…` для непривязанных). Нынешняя `tg-app` меняется только в одном: проверка подписи Telegram выносится в общий модуль.
- **Сайт:** раздел «Билеты классу» (запуск, таблица, разбор по вопросам, Excel), кнопка «Запустить классу» у набора; страница `/exam` для ученика.
- **Тесты:** чистая логика (очистка снимка от ответов, подсчёт баллов, случайный вариант, сроки) и права доступа (ученик не видит ключ и чужие попытки, вторая попытка не создаётся, чужой преподаватель не видит результаты).
- **Не трогаем:** подбор билетов, Word, проверку бланков, нынешнее мини-приложение.

## Риски
- **Утечка ключа** — главный. Защита: ответы вырезаются на сервере, тест на это обязателен.
- **Списывание.** Случайные варианты, одна попытка, таймер; полной защиты на личном телефоне нет. Соседям может выпасть один вариант.
- **Нет Telegram у ученика** — сдаёт на бумаге, как сейчас.
- **Преподаватель без привязанного Telegram** — таблица только на сайте, кнопки бота недоступны.
- **Обрыв связи** — ответы сохраняются по одному, работа не теряется; таймер при этом идёт.
- **Лимиты Telegram** на частоту сообщений: таблица переписывается не чаще раза в несколько секунд, разбор рассылается с паузами.

## Этапы
1. Основа: таблицы, ссылка, прохождение (тесты, соответствия, открытые, тексты английского), баллы ученику.
2. Раздел «Билеты классу»: запуск, таблица, закрытие, Excel.
3. Разбор по вопросам для преподавателя и рассылка разбора ученикам текстом.
4. Позже: кластерные книжки, страница без Telegram, оценка качества вопросов по этим результатам.
